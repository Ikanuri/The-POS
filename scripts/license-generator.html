📷 Scan Serial dari HP Pelanggan
Arahkan kamera ke QR sidik jari yang tampil di layar aktivasi/ info-lisensi The POS — mengisi kolom di bawah otomatis, tanpa ketik manual.
Browser ini belum mendukung pemindaian QR native (BarcodeDetector). Coba Chrome/Edge terbaru di Android, atau ketik sidik jari manual di bawah.
Browser menolak izin kamera — bukan bug alat ini. Banyak browser (terutama Chrome di Android) menolak otomatis TANPA menampilkan dialog izin sama sekali kalau halaman HTML dibuka langsung dari file manager/Downloads (file://), bukan lewat alamat web.

Cara paling andal (sekali jalan, dari folder tempat file ini disimpan):
python3 -m http.server 8000 (kalau ada Python) atau npx serve . (kalau ada Node.js) — lalu buka http://localhost:8000/ di browser yang sama.

Tanpa itu, ketik sidik jari manual saja di kolom bawah — tetap berfungsi normal.
